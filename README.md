# INFOKILAS GitHub Pages

Unggah isi folder ini ke root repository `infokilas.github.io` pada branch `main`.

- Tambahkan kode verifikasi Google Search Console yang SUDAH dipakai ke `_includes/head.html` sebelum mengganti file tersebut.
- Logo: `assets/images/logo-infokilas.png`.
- Banner artikel: `assets/images/banner-mahjong1.jpg`.
- Artikel ditulis di `_posts/YYYY-MM-DD-slug.md`, dengan front matter pada baris pertama.
- Pengaturan Pages: Deploy from a branch > main > /(root).
- Sitemap otomatis: https://infokilas.github.io/sitemap.xml.
- Jangan simpan dua file dengan URL permalink yang sama.
